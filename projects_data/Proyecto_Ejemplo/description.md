# Descripción del Proyecto (Overview)

Este archivo **DEBE** llamarse exactamente `description.md` y debe ubicarse en la raíz de la carpeta del proyecto (por ejemplo, `projects_data/Proyecto_Ejemplo/description.md`).

## ¿Para qué sirve?
El contenido de este archivo se renderiza automáticamente en la pestaña **Overview** (Resumen) del proyecto en la aplicación web. Su objetivo es proporcionar una vista rápida de qué trata el proyecto, quiénes están involucrados, los objetivos principales o cualquier otra información de alto nivel.

## Formato
Puedes usar todo el poder de **Markdown** aquí:
- **Negritas** y *cursivas*.
- Listas y viñetas.
- Fragmentos de código en línea o bloques de código.
- Enlaces y demás.

Como este archivo es tu portada, intenta mantenerlo organizado y limpio. Puedes editarlo directamente desde tu editor de código o mediante la interfaz de la aplicación en la pestaña Notes (dependiendo de la configuración de visibilidad de la app).
