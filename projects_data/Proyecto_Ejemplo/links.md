# Enlaces del Proyecto (Documents)

Este archivo **DEBE** llamarse exactamente `links.md` y debe ubicarse en la raíz del proyecto.

## ¿Para qué sirve?
Se utiliza para poblar la pestaña **Documents** (a veces llamada Links en iteraciones anteriores). Sirve como un repositorio central de URLs importantes relacionadas con tu proyecto: carpetas de Drive, repositorios de código, tableros de Jira, documentos de arquitectura, etc.

## Formato esperado
La aplicación parsea los enlaces utilizando el formato de listas y enlaces de Markdown.

- [Carpeta de Google Drive del Proyecto](https://drive.google.com/drive/folders/ejemplo)
- [Repositorio de GitHub](https://github.com/ejemplo/repo)
- [Tablero de Trello / Jira](https://trello.com/ejemplo)

Puedes agruparlos bajo encabezados si quieres organizarlos visualmente:

- [Arquitectura de la solución](https://docs.google.com/document/d/ejemplo)
