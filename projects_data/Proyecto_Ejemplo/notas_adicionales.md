# Notas Libres

Cualquier archivo `.md` (Markdown) que crees en la carpeta del proyecto y que NO se llame `description.md`, `tasks.md`, `links.md` o `talks.md`, la aplicación lo tratará como una nota general.

## ¿Dónde aparece?
Aparecerá listado en la pestaña **Notes**. Puedes crear tantos como necesites:
- `reunion_2026_04_23.md`
- `ideas_arquitectura.md`
- `minutas.md`

Es la forma de llevar la documentación libre del proyecto usando archivos planos sin necesidad de una base de datos externa.
La pestaña Notes te permite visualizar y editar estos archivos (según la configuración de tu editor).
