# Bienvenido a Proyecto Ejemplo

Esta carpeta es una plantilla o guía que contiene **ficheros placeholder** (de relleno) para cada tipo de contenido que soporta la aplicación. 

El objetivo es que puedas entrar en cada fichero, leer su contenido y entender **para qué sirve**, **cómo se debe nombrar** y **qué formato interno** espera la aplicación para que la visualización sea correcta en las diferentes pestañas (Overview, Tasks, Links, Notes, Meetings, Documents, Talks).

A la izquierda en el menú deberías ver este proyecto "Proyecto Ejemplo". Explora sus pestañas y verás cómo la aplicación interpreta los archivos que hay aquí dentro.

## Tipos de archivos especiales
- `description.md`: Se muestra en la pestaña Overview.
- `tasks.md`: Genera la lista de tareas interactiva en la pestaña Tasks.
- `links.md`: Alimenta la lista de enlaces de la pestaña Documents/Links.
- `talks.md`: Crea la pestaña Talks con tarjetas de charlas o conferencias.
- `*_transcripcion.txt` y `*_transcripcion_resumen.txt`: Son los archivos que la aplicación genera cuando transcribes y resumes un video de reunión.
- Cualquier otro archivo `.md` (ej. `notas_adicionales.md` o este `README.md`): Se mostrará en la pestaña Notes como una nota independiente.
