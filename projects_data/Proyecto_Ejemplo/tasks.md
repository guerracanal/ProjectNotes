# Tareas del Proyecto

Este archivo **DEBE** llamarse exactamente `tasks.md` y debe ubicarse en la raíz del proyecto.

## ¿Para qué sirve?
Alimenta la pestaña **Tasks**. La aplicación escanea este archivo en busca de listas de tareas tipo Markdown y las renderiza en una interfaz donde puedes marcar o desmarcar las casillas, y las fechas de creación se asocian automáticamente si añades nuevas tareas por la interfaz de la app.

## Formato requerido
Debes usar el formato estándar de tareas en Markdown (`- [ ]` para pendiente y `- [x]` para completado).

- [x] Tarea de ejemplo ya completada.
- [ ] Tarea de ejemplo que falta por hacer.
- [ ] Otra tarea pendiente.

Si no usas la sintaxis exacta de checkboxes (`[ ]` con un espacio en medio, o `[x]` minúscula), la aplicación no lo reconocerá como una tarea interactiva.
